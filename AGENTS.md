# AGENTS.md

Guidance for AI agents (and people) working in this repository.

This is the FKMTime user documentation site, built with Docusaurus. Pages live
in `docs/`; downloadable files (firmware, assembly files) live in `static/`.
The app itself is in [FKMTime/FKMTime](https://github.com/FKMTime/FKMTime).

## Rules

- **The brand is "FKMTime"**: one word, exactly that capitalisation, in every
  page, heading, sidebar label and commit. Never "FKM", "FKM Time" or
  "Fkmtime". That includes the hardware: "FKMTime devices", "FKMTime
  stations".
- Existing file names and URLs keep their real spelling, even when they use
  "FKM" or "fkm" (`FKM - Case.stl`, `fkm-v4.md`, `fkmtime.local`). Renaming them
  breaks links.
- Match the wording in the app's UI when describing it; check the app if
  unsure.
